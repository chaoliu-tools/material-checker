# 标书材料清单检查器（本地初版）

A small, offline, standard-library CLI for checking attachment filenames against a manually maintained CSV checklist.

给准备投标材料的人做一次**材料存在性辅助检查**：找出未找到的必需附件，以及多个候选、版本或跨要求共用文件等需要人工判断的情况。

**它不读取或理解材料正文，不判断格式、签章、有效期、资质真实性或投标合规，不保证中标，也不是 AI 全自动标书系统。** 单候选“已找到”只说明名字匹配。请先由负责人根据招标原文维护完整清单，再人工核对每项正文。

## 快速运行

需要 Python 3.9 或更新版本；无需安装包，无网络、模型、API 密钥或外部服务依赖。本次验证环境为 macOS / Python 3.9；其他操作系统尚未验证。

在本项目目录运行：

```sh
python3 checker.py --requirements examples/requirements.csv --materials examples/materials --output demo-report
```

示例有意保留问题，**预期退出码为 1**，并生成 `demo-report/report.html`、`report.csv`、`report.json`。手动打开 HTML 即可查看，不需要启动服务器。再次运行请改为 `--output demo-report-2`，程序不会覆盖旧报告。

仓库内 `sample-report/` 是本次实际运行生成的样例，可直接查看。

示例文件是自行编写的虚构 `.txt` 占位材料，不是真实企业、客户、资质或报价文件。示例结果：已找到 2 项、必需缺失 1 项、多版本待复核 1 项、可选未提供 1 项。

## 输入清单

UTF-8（支持 BOM）的 CSV，表头顺序必须精确如下：

```csv
id,title,required,pattern
R01,虚构登记材料,yes,虚构登记材料.txt
R02,虚构资格材料,yes,虚构资格材料_v*.txt
R03,虚构授权材料,yes,虚构授权材料.txt
```

- `id`：非空、唯一；不会自动修正重复 ID。
- `title`：人工填写的材料要求名称，非空。
- `required`：只允许 `yes`（必需）或 `no`（可选）。
- `pattern`：非空文件名，区分大小写；`*` 匹配任意长度字符，`?` 匹配单个字符。递归查找所有子目录，规则只比对文件名。路径分隔符、冒号、方括号、`**` 和路径 `.`、`..` 不允许。不支持正则表达式、路径规则、模糊语义识别。
- 字段首尾空白会去除；字段内控制字符不允许；全空物理行忽略。缺列、多列、错误表头、空清单、无效 UTF-8 均报错。

建议规则尽量具体。过宽的 `*.pdf` 即使只有一个候选也不能证明该文件满足要求；规则质量和清单完整性由人工负责。

## 结果与退出码

| JSON/CSV 状态 | 含义 |
| --- | --- |
| `found` | 仅一个文件名候选，正文仍需人工复核 |
| `missing` | 必需要求无候选 |
| `optional_missing` | 可选要求无候选 |
| `review` | 多个候选/版本，或候选被多个要求匹配；不会自动选“最新” |

退出码 `0`：没有必需缺失或匹配歧义，**不表示投标合规**；`1`：存在缺失或待复核项，报告正常生成；`2`：参数、输入或文件系统错误，不能得出完整结论。发生写盘错误时可能留下不完整输出目录，必须忽略其中的报告，换新目录重跑。

JSON 包含版本号、生成时间、输入路径、扫描文件数、状态计数、规则和候选相对路径。CSV 使用 UTF-8 BOM，便于中文表格软件读取；对以 `= + - @` 开头（包括前导空白）的单元格加单引号防常见公式注入，因此导出的显示值可能多一个单引号；原值保留在 JSON。不要移除防护后把不可信值作为公式导入。

## 文件与隐私边界

- 只读取指定要求 CSV；材料只枚举文件名及文件类型，不打开正文，不修改、重命名或删除材料。
- 所有输入及输出路径的各级软链接均拒绝，包含 `..` 的路径拒绝；材料树内任何软链接（含断链、内部链接）或非普通文件均使检查报错，不静默跳过。
- 输出必须是一个不存在的新目录，其父目录必须存在，且输出不能位于材料树内。已有文件、目录、链接均不覆盖。
- macOS 的 `/tmp`、`/var` 常是系统软链接；请使用其真实路径（例如 `/private/tmp`）或本项目普通目录，而不是绕过检查。
- HTML 转义所有输入文本且无脚本、外部资源和可点击材料链接。报告含文件名及本地绝对输入路径，仍可能敏感；分享前人工检查。本次所有报告仅使用虚构示例。
- 检查是静止本地目录的一次名称快照。不要在运行中修改目录；不提供对恶意本地进程并发替换路径的安全隔离，不把它当作处理不可信文件系统的沙箱。
- 空文件、错误扩展名、无效 PDF 等仍可能“已找到”，因为不读取正文；文件名含多个版本时只列候选，不判断优先级。
