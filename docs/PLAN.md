# 标书材料清单检查器：初版设计与执行计划

授权范围：独立本地项目，Python 3 标准库，只用合成示例，不发布、不选定许可证。

设计：`checker.py` 提供 CLI。输入 UTF-8 CSV，字段为 id,title,required,pattern；required 仅 yes/no；pattern 为区分大小写的文件名匹配（*、?），不接受路径。递归枚举指定材料目录的普通文件，只读名称及文件类型，不打开材料内容。单候选标记 found；必需零候选 missing；可选零候选 optional_missing；多候选或跨要求共用文件标记 review。始终要求人工核对正文、签章、有效期及投标要求。

输出：新目录内 report.html、report.csv、report.json；HTML 转义，CSV 危险单元格加单引号，JSON 保留原值。退出码 0 表示没有必需缺失/匹配歧义，1 表示有待处理项，2 表示输入/文件系统错误。没有“合规通过”结论。

边界：拒绝输入路径组成部分中的软链接；材料树发现软链接或非普通文件即报错；输出不得位于材料树内，也不得是既有目录。要求静止的本地目录，不提供并发恶意替换路径的安全隔离。
